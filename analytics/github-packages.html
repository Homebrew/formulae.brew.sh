Source and definitions

Source: GitHub Packages and Homebrew install analytics; JSON includes source URLs, dates and {{ data.unavailable_formulae.size | number_with_delimiter }} unavailable packages.

Formula: Current core formula name; versioned formulae are separate, with casks and other taps excluded.

Downloads: GitHub’s cumulative package downloads across versions and platforms since the Bintray migration; earlier downloads are excluded.

30-day: Sum of GitHub’s daily download chart, including today’s incomplete value.

Installs: Reported installation attempts over 30 days, including dependencies, source builds and CI.

Ratio: 30-day downloads divided by install events, or N/A when zero; 2× means twice as many downloads.

Windows can differ, and retries, caches and other clients affect counts; the ratio does not measure analytics opt-outs.

Top {{ data.selected_formulae | number_with_delimiter }}: Sums all available packages in the JSON; Ratio is the arithmetic mean of their available download/install ratios.
