Source and definitions

Source: Homebrew/brew Git history and tags, generated {{ data.generated_at }}; JSON.

Version / Date: Stable numeric release tag and its UTC commit date; missing tags cannot be counted.

Commits: Non-merge commits since the preceding release tag on the same branch; the first release includes preceding history.

PRs: Distinct PR references in merge or squash subjects within that range; missing references are excluded.

Contributors: Distinct non-merge author email identities in the range after the current mailmap, including bots and excluding co-author trailers.

New contributors: Identities appearing in a stable release for the first time, ordered by tagged commit date then version.

Backports can repeat commits and contributors across releases; annual release totals are in repository analytics.

Since: Additional rows at each .0 release cover changes since the preceding major or minor .0 tag; New counts authors absent from that preceding tag’s history.

Current: Unique commits, PR references and contributors across all {{ data.totals.releases | number_with_delimiter }} release tags as of the generation date; overlapping ranges count once.
