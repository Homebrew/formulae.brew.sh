Formula findings

Source and definitions

Source: Advisory index and current formula versions using brew vulns matching; JSON.

Version: Upstream version followed by _$REVISION when the package revision is nonzero, using its actual revision number.

Open / Critical / High: Records affecting the evaluated version, including ranges not established as fixed, with critical and high severity counts.

Patched / Fixed: Records resolved by a Homebrew patch or version change; these are current statuses.

Total: Formula-specific findings across all rows; vulnerabilities affecting several formulae count for each.
